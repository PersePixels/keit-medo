## keit-medo
> A text chat system for RedM, It's very much a WIP but, some ideas are visible here at least!

## Features
- /me, /do, and /sy commands, that display text over your character (/sy being an integrated option for silent players who want the benefit of having an 'implied voice', without being lumped into 'sign language')

- integration with mumble (pma-voice), that renders text at the same distance as the players voice range
